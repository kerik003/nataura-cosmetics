# NATAURA.COSMETICS

Интернет-магазин на Next.js + Supabase + Vercel. Оплата: наложенный платёж и
Monopay (Monobank Acquiring). Доставка: Нова Пошта (город + отделение с
автокомплитом). Уведомления о заказах — в Telegram.

## Что уже готово

- Каталог с категориями (структура повторяет разделы cosmeticus.com.ua —
  тексты и фото НЕ скопированы, их нужно добавить свои)
- Карточка товара с выбором объёма: недоступные объёмы видны, но не кликабельны
- Корзина (хранится в localStorage браузера)
- Чекаут: автокомплит города и отделения Новой Почты, выбор оплаты
  (наложенный платёж / Monopay)
- При оформлении заказа: проверка актуального наличия, списание остатка,
  уведомление в Telegram, создание инвойса Monopay (для онлайн-оплаты)
- Простая админ-панель (`/admin`): добавление товаров с фото и объёмами,
  переключение "в наявності / немає" по каждому объёму отдельно, список
  заказов со сменой статуса

## Что нужно донастроить перед стартом

### 1. Supabase
1. Создайте проект на supabase.com
2. В **SQL Editor** выполните файл `supabase/schema.sql` целиком
3. В **Storage** создайте публичный bucket с именем `products`
   (Settings → Public bucket = ON)
4. Создайте первого администратора:
   - Authentication → Users → Add user (email + пароль)
   - Скопируйте его `User UID`
   - В SQL Editor выполните:
     ```sql
     insert into admin_users (user_id, full_name) values ('ВСТАВЬТЕ_UID', 'Ваше имя');
     ```
5. Скопируйте `Project URL`, `anon public key` и `service_role key` из
   Settings → API — они понадобятся в `.env`

### 2. Nova Poshta
У вас уже есть ключ разработчика — впишите его в `NOVA_POSHTA_API_KEY`.

### 3. Monopay (Monobank Acquiring)
1. Зарегистрируйтесь как продавец: https://acquiring.monobank.ua
2. В личном кабинете получите `X-Token` → впишите в `MONOPAY_TOKEN`
3. Webhook уже реализован на `/api/monopay/webhook` — Monobank сам его
   вызовет после оплаты, ничего дополнительно указывать не нужно

### 4. Telegram-бот (для уведомлений о заказах)
1. Напишите **@BotFather** в Telegram → `/newbot` → задайте имя и username
   бота → получите **токен** (впишите в `TELEGRAM_BOT_TOKEN`)
2. Создайте группу/канал для заказов, добавьте туда бота как администратора
3. Узнайте **chat_id**: напишите любое сообщение в группу, затем откройте
   `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates` в браузере —
   в ответе найдите `"chat":{"id": -100...}` → это и есть `TELEGRAM_CHAT_ID`

### 5. Локальный запуск
```bash
cp .env.example .env.local   # и заполните все значения
npm install
npm run dev
```

### 6. Деплой на Vercel
1. Залейте проект в GitHub-репозиторий
2. Импортируйте репозиторий на vercel.com
3. В Project Settings → Environment Variables добавьте все переменные
   из `.env.example`
4. Deploy

## Структура проекта

```
app/
  (shop)/catalog/[categorySlug]   — страница категории с фильтрами
  (shop)/product/[slug]           — карточка товара
  (shop)/cart                     — корзина
  (shop)/checkout                 — оформление заказа
  admin/login                     — вход в админку
  admin/(protected)/products      — управление товарами и наличием
  admin/(protected)/orders        — заказы
  api/novaposhta/cities           — поиск города (Nova Poshta API)
  api/novaposhta/warehouses       — поиск отделения (Nova Poshta API)
  api/checkout                    — создание заказа, списание остатка,
                                     Telegram-уведомление, Monopay-инвойс
  api/monopay/webhook             — подтверждение оплаты от Monobank
supabase/schema.sql                — вся структура БД одним файлом
```

## Что стоит сделать дальше

- Наполнить каталог реальными товарами (свои фото и описания —
  не копии с других магазинов, это важно для SEO и легальности)
- Добавить страницу "Доставка і оплата", "Контакти", политику оферты
- Подключить логотип (когда пришлёте — вставлю в шапку сайта)
- При желании — расширить фильтры каталога (сейчас подключён "Тип шкіри",
  остальные группы атрибутов в схеме уже созданы и легко добавляются)
